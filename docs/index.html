Empowered Recall

Riot Games Hackathon at DevHack, Nov 2026. Team of 3.

  • Unity
  • C#
  • AI agents
  • MCP
  • Hot Reload

A tool for trying game design ideas in seconds instead of days. Freeze a playtest, select the objects the agent may touch, and describe the change. The agent patches the game live without a recompile or restart.

  • A second, sandboxed agent runs regression tests on every edit, such as making sure players can't damage allies.
  • Every change is saved as a snapshot, so any edit can be undone in one click.
